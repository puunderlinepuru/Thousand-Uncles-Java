# Строение проекта

## discord_bot
Бот, делает штуки которые делает бот.
### Команды:
- /ping
    - Pong!
- /check
    - Достает записи из базы данных PostgreSQL, созданные и обновляемые **google_api_handler**
- /teach
    - Добавляет фразу в словарь `/discord_bot/resources/dictionary.yml`. (Зачем словарь написано дальше)
- /coinflip
    - Бросок монетки с тремя опциональными полями ***reason*** - что определяет бросок, ***heads*** - что если орел, ***tails*** - что если решка
### Отдельные фичи
- Если бота пингуют в выделенном **meme channel** он достает одну случайную фразу из ^Словаря и вбрасывает в чат.
    - При этом если в сообщении с пингом присутствует "?" бот вбрасывает случайный да\нет\может быть ответ.

## google_api_handler
Обновляет `/shared_resources_space/records.yml` (предполагается как локальное хранилище записей на случай перебоев в БД) и БД PSQL данными из **Google Sheets** каждый час.

## dashboard
API для манипуляци данными в БД. Потом добавлю веб-визуал с настройками и монитором всего подряд.

## PostgreSQL
Главное хранилище данных
